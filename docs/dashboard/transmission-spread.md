# Transmission & Spread

!!! info "Section in progress"
    This page will walk the six labelled sections (A–F) of the Transmission &
    Spread panel: query subtree + outbreak history (A), closest relatives vs
    burden over time (B), R(t) at sampling (C), genetic transmission cluster
    (D), historical strain behaviour (E), and the transmission assessment
    (F).

## What this page answers

*How did this lineage spread historically, how intense was transmission where
the query sits, and is the query part of an ongoing cluster?*

!!! note "No forecasts by design"
    Earlier versions projected future cases. That section was removed: the
    pipeline doesn't collect enough covariates to project responsibly, so the
    panel reports observed history and fitted estimates only.
